# Достойный уход за питомцем — usyplenie.103vet.by

Информационный статический сайт проекта ветеринарной клиники **[103vet.by](https://103vet.by)**, посвящённый паллиативной помощи и достойному уходу за тяжелобольными питомцами на дому в Минске и Минской области.

Сайт помогает владельцам животных:

- распознать тревожные симптомы скрытых заболеваний у кошек и собак;
- понять, как организовать паллиативный уход дома (питание, контроль боли, адаптация пространства);
- оценить качество жизни питомца и принять взвешенное решение;
- получить ответы на частые вопросы и связаться с клиникой.

**Домен:** `https://usyplenie.103vet.by/` · **Язык:** русский (`ru`, `og:locale ru_BY`) · **Гео-привязка:** Минск (BY-MI)

## Технологии

| Компонент | Описание |
|---|---|
| HTML5 | Семантическая разметка, Schema.org (JSON-LD, тип `VeterinaryCare`), Open Graph, гео-теги |
| CSS3 | Единый стилевой файл с CSS-переменными (`:root`), Flexbox, `clamp()` для адаптивной типографики, SVG-текстура фона через data-URI |
| Google Fonts | Playfair Display (заголовки) + Inter (текст) |
| Google Analytics 4 | gtag.js, идентификатор `G-PYHE23TN5H` |
| SEO | `robots.txt`, `sitemap.xml`, canonical-ссылки, верификация Bing (`BingSiteAuth .xml`) |

Сборщики, фреймворки и серверная часть **не используются** — это чистый статический сайт, который можно разместить на любом хостинге (в т.ч. GitHub Pages / Netlify / Vercel) без сборки.

### Главная страница (`index.html`)

Одностраничный лендинг-хаб со следующими блоками (якоря):

- **Герой** — «Последняя забота», CTA-кнопки;
- `#philosophy` — философия проекта и оценка качества жизни;
- `#palliative` / `#pomoshch-vladeltsu` — помощь владельцу в принятии решений;
- Блок навигации по разделам («Выберите раздел, который соответствует вашей ситуации») со ссылками на все 18 внутренних страниц (кошки, собаки, шкала HHHHHMM);
- `#FAQ` — частые вопросы;
- Контакты: `mailto:care@103vet.by`, ссылка на клинику `https://103vet.by`.

### Внутренние страницы

Все внутренние страницы (`pages/cat/`, `pages/dog/`, страницы шкалы HHHHHMM в корне `pages/`) используют:

- относительную ссылку на стили (`../../../css/styles.css`);
- абсолютные ссылки на главную и соседние материалы (`/`, `/pages/cat/...`) — кросс-навигация между статьями;
- единый дизайн и структуру мета-тегов (title, description, canonical, OG).

## SEO и аналитика

- **`sitemap.xml`** — содержит все 19 страниц с приоритетами (главная `1.0`, обзорные/разделочные страницы и тест HHHHHMM `0.8`, детальные статьи `0.7`). Кириллические имена файлов в `<loc>` записаны в URL-кодированном виде (percent-encoded), как того требует стандарт sitemap.
- **`robots.txt`** — разрешает обход всего сайта, запрещает служебные директории (`/result_pages/`, `/.git/`, `/.osp/`) и временные файлы (`*.cmd`, `*.txt`), указывает путь к sitemap, `Crawl-delay: 1`.
- **Schema.org (JSON-LD)** — размечена организация типа `VeterinaryCare` с адресом, телефоном и описанием.
- **Canonical** — все страницы ссылаются на домен `usyplenie.103vet.by`.
- **Google Analytics 4** — подключён через gtag.js на главной странице.
- **Bing** — верификация через `BingSiteAuth .xml` (обратите внимание: в имени файла есть пробел перед расширением — при переносе на другой хостинг проверьте, что Bing корректно читает файл; при необходимости переименуйте в `BingSiteAuth.xml`).

## Локальный запуск

Сборка не требуется. Достаточно открыть файлы в браузере или поднять простой статический сервер:

```bash
# Python
python3 -m http.server 8000
# затем откройте http://localhost:8000

# или Node.js
npx --yes serve .
```

> Из-за абсолютных ссылок (`/pages/...`, `/#FAQ`) навигация между страницами корректно работает через локальный сервер, а не при открытии файлов по `file://`.

## Деплой

Любой статический хостинг, поддерживающий домен `usyplenie.103vet.by` (например, GitHub Pages, Netlify, Vercel, классический shared-хостинг по FTP). Корень репозитория = корень сайта. Сборочные команды отсутствуют.

## Как добавить новую статью

1. Создайте файл в нужной категории, например `pages/cat/simptomy/koshki_simptomy_novaya_temа.html` или `pages/dog/simptomy/Новая_тема_u_sobak.html`, скопировав структуру существующей статьи (мета-теги, навигация, подключение `../../../css/styles.css`).
2. Добавьте ссылку на неё с главной страницы (`index.html`) и из связанных статей.
3. Допишите `<url>` в `sitemap.xml` с актуальной датой `lastmod`.
